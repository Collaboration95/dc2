Team 17 · NUS Architecting Scalable Systems · Project 2

FlickPond

FlickPond is a video processing platform. An owner uploads a video, the platform converts it into an MP4 and adaptive HLS streams (360p, 480p, 720p), and only that owner can play the result. Any application can use it through one public API: the team built two, a browser app and a command-line Publisher, and it runs on AWS in ap-southeast-1.
