The project in one breath

FlickPond is a reusable video-processing platform. A browser app and a Publisher command-line client use the same public APIs to upload an owner’s video, track background conversion and play the result. Media owns the user’s content; Processing owns the work.

Read all diagram notes
  • An owner uploads — Maya and Arun represent content owners. Clients ask for permission, then send the video bytes directly to S3.
  • Media accepts — Media checks the uploaded object, pins an immutable version and records the processing command in its database transaction.
  • Processing converts — Processing tracks the job and attempt. A finite Fargate worker encodes only after obtaining a valid lease.
  • The owner plays — A result updates Media’s local view. Media checks ownership before returning temporary playback access.
