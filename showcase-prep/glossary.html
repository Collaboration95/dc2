Reference / Language without the fog

What do these words mean?

A short definition, then the specific meaning in FlickPond.

ACU · Aurora Capacity Unit

Aurora Serverless compute unit.

Here: 0 ACU: compute paused, storage still costs, next request not instant.

See it in the project →
Adapter

Code translating one interface into another.

Here: Gateway adapter turns an API Gateway event into a FastAPI request.

See it in the project →
Aggregate

Related state with shared consistency rules.

Here: An owned asset and a processing job are separate consistency centers in different services.

See it in the project →
AISS

The report's register of architecture issues, AISS-01..05.

Here: Performance misses; public API beyond CloudFront and no WAF; image-only rollback; operations hardening; evidence not established.

See it in the project →
Alembic / migration

A tool and ordered scripts for evolving database structure.

Here: Each owner has its own history; released bytes are preserved; image rollback does not undo a migration.

See it in the project →
API Gateway

AWS service receiving HTTP requests and invoking integrations.

Here: Routes /api/media and /api/processing to Lambda handlers.

See it in the project →
API · Application Programming Interface

A contract for asking another program for work or data.

Here: Browser and Publisher use public HTTP, not database or queue credentials.

See it in the project →
Artifact

A build or verification output, such as an image or test report.

Here: CD needs source-matched evidence and immutable image identity, not a latest tag.

See it in the project →
ASGI

Async Python interface between web server and application.

Here: FastAPI speaks ASGI; an adapter connects it to API Gateway events.

See it in the project →
Asset / job / attempt

The owned resource, work requested for it, one execution of that work.

Here: A failed job retries from the same source with a new attempt and lease.

See it in the project →
Aurora auto-pause / resume

Idle database compute drops to zero and resumes on demand.

Here: Each cluster pauses at 0 ACU; one observation reached 0.0 ACU about 56 minutes after the last upload. Not a cost or resume-latency measurement.

See it in the project →
Authentication / authorization

Authentication identifies the caller; authorization decides what they may do.

Here: A valid Arun session must still be denied Maya's video.

See it in the project →
Availability Zone

An isolated location within an AWS region.

Here: VPC spans two zones, but each Aurora cluster is one instance: subnet spread is not high availability.

See it in the project →
bcrypt

A deliberately slow password-hashing algorithm.

Here: Media stores and verifies hashes; never recovers the password.

See it in the project →
Bounded context

A boundary where terms, rules and data ownership are consistent.

Here: Media owns content and reads; Processing owns attempts and execution.

See it in the project →
Branch coverage

Whether both outcomes of each decision ran.

Here: Shows untested recovery and authorization decisions better than statement coverage.

See it in the project →
CI / CD

CI automates checks on change; CD automates applying a verified release.

Here: GitHub Actions picks lanes; eligible green Main CI triggers delivery to dc2-live.

See it in the project →
CloudFormation

AWS infrastructure definitions creating resources as a stack.

Here: Python renders the template; the persistent stack is dc2-live.

See it in the project →
CloudFront

AWS content delivery network.

Here: Serves the static frontend from private S3 and forwards /api to the HTTP API.

See it in the project →
CloudWatch

AWS logs, metrics, dashboards, alarms.

Here: Task activity, database capacity and alarms explain operations; a past OK snapshot is not continuous proof.

See it in the project →
Cold start / task startup

Initialization delay before a process or container can work.

Here: Fargate queue wait includes task creation-to-start. Lambda submit-to-done: 92.0 s cold vs 45.2 s warm.

See it in the project →
Container image / container

An image is a packaged filesystem and runtime config; a container runs it.

Here: Three images (Media, Processing, encoder); Lambda and Fargate both run image-packaged code.

See it in the project →
Contract

The agreed shape and meaning of communication between components.

Here: OpenAPI describes HTTP operations; contracts/v1.py defines actors, source descriptors, message envelopes.

DAST / SAST

DAST tests a running application; SAST analyzes code without running it.

Here: ZAP gives bounded authenticated DAST; Ruff security (Bandit rules) checks patterns, not data flow. Sonar is unconfigured.

DDD · Domain-driven design

Organizing software around domain language, responsibilities and consistency rules.

Here: The key decision is who owns assets versus attempts, not folder layout.

See it in the project →
Dead-letter queue / DLQ

A queue for messages that repeatedly failed consumption.

Here: Every work/command/result queue has one; it does not prove business recovery.

Digest / configuration ID

A cryptographic identity for image bytes or configuration, not a mutable label.

Here: Manifest digests must be bound to the configurations the scans checked.

See it in the project →
ECR · Elastic Container Registry

AWS container image registry.

Here: Holds Media, Processing and worker builds for Lambda and Fargate.

See it in the project →
ECS / Fargate

Fencing

IAM / least privilege

Idempotency

JWT / session cookie

Lambda / alias / short lane

Lambda runs event-driven functions; an alias names a published version.

Here: Release moves the live alias with checks and a restore path. Short lane: clips ≤60 s, ≤64 MiB, ≤1080p go to a Lambda container encoder.

Lease / heartbeat

A temporary right to work, renewed while healthy.

Here: Database clock, attempt identity and token decide whether a worker may finish.

Migration compatibility

See it in the project →
