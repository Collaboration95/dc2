into three elapsed days of agentic coding, five days maximum. Apply the 80/20

concrete required gap, not new product scope; no automatic extension beyond five.
Actual course report and presentation work remain separate required work.

broker or elaborate security infrastructure. This supersedes heavier deployment
suggestions in the design pack. Current authorisation covers implementation
across inherited tracks; historical Project 1 ownership/PR-only rules are not gates.

  project's configuration is not this project's account. No provisioning yet.

  evidence and a recording fallback for the presentation.

  inherited Alibaba deployment. Local work can proceed before AWS prerequisites.
