## Official AWS assumptions checked

- ECS RunTask is eventually consistent and may return both tasks and failures. Use pinned task-definition revision, persist response identity, and reconcile with bounded DescribeTasks/backoff rather than assume a successful HTTP response started every requested worker. [AWS RunTask](https://docs.aws.amazon.com/AmazonECS/latest/APIReference/API_RunTask.html).
- `ListTasks(desiredStatus=PENDING)` returns no tasks; desired status and last status differ. Query/paginate RUNNING and STOPPED desired-status inventories and describe known/reserved ARNs; include lastStatus PENDING and other nonterminal tasks in cap/close logic. `startedBy` cannot be combined with other filters. A temporarily absent ARN remains unresolved. [AWS ListTasks](https://docs.aws.amazon.com/AmazonECS/latest/APIReference/API_ListTasks.html).
- Retry ambiguous RunTask requests with the same client token and original parameters. Token lifetime is the smaller of 24h or task lifetime plus one hour, so a durable operator journal must not treat tokens as permanent uniqueness. After expiry, reconcile the old launch before permitting a new operation. [AWS ECS idempotency](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/ECS_Idempotency.html).
- Fargate container stop timeout defaults to 30s and maxes at 120s. Pre-stop drain can be longer because StopTask has not yet started that countdown. [AWS ContainerDefinition](https://docs.aws.amazon.com/AmazonECS/latest/APIReference/API_ContainerDefinition.html).
- ECS does not replace stopped standalone tasks; services and standalone tasks have distinct ownership. An operator can replace lost capacity without changing the failed attempt semantics. [AWS Fargate task maintenance](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/task-maintenance.html).
- Fargate charges requested task resources from image download until termination, per second with a Linux one-minute minimum. A 1536-MiB container limit does not lower the 4-GiB task bill. Record image-pull/task termination timings and IPv4 exposure separately; startedAt alone undercounts compute residency. [AWS Fargate pricing](https://aws.amazon.com/fargate/pricing/).

These are documentation checks, not authenticated resource observations. No account-specific quota, availability, permission, cold start or price eligibility was verified.
